# Consent document font

Unmodified **Noto Sans Georgian v2.005**, downloaded from the official Google Fonts
repository on 2026-10-09. The variable font covers Georgian and Latin, including English.
No remote font request is made by the consent workflow. Completed HTML artifacts embed
these font bytes and the complete copyright and license text.

- Font source: https://github.com/google/fonts/tree/main/ofl/notosansgeorgian
- Upstream source repository: https://github.com/notofonts/georgian
- Upstream release: https://github.com/notofonts/georgian/releases/tag/NotoSansGeorgian-v2.005
- Upstream source commit recorded in the official metadata:
  `c02e5483c2dd63c5cf223845010ebd6e6dc56aec`.
- License: **SIL Open Font License 1.1**. Full original text is in
  `OFL-NotoSansGeorgian.txt`. Copyright 2022 The Noto Project Authors.
- Original source filename: `NotoSansGeorgian[wdth,wght].ttf`.
  Only its filesystem filename is shortened here to `NotoSansGeorgian.ttf`.
- SHA-256: `dc591156f36842d38996c4a7a17fee9bb58e45da3e2cac7a31b7d33de700adb9`.
- `NotoSansGeorgian-METADATA.pb` is the accompanying original upstream metadata.

Pillow is the only new Python runtime dependency for this feature. The font adds no
font-processing dependency, signing SDK, PDF renderer, browser server, or external service.
